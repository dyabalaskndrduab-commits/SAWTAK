# صوتك — مساعد إدارة الهاتف بالصوت

مشروع Android Native بلغة Java، بواجهة عربية مصرية، وتنشيط صوتي بعبارة «يا مساعد» أثناء تشغيل خدمة الاستماع.

## أوامر النسخة الحالية
- يا مساعد افتح واتساب / يوتيوب / الكاميرا / الإعدادات
- يا مساعد افتح البلوتوث / الواي فاي (يفتح صفحة الإعدادات؛ لا يغيّر المفتاح مباشرة)
- يا مساعد شغّل الكشاف / اقفل الكشاف
- يا مساعد ارفع الصوت / وطي الصوت / اكتم الصوت
- يا مساعد كم البطارية؟ / الساعة كام؟
- يا مساعد اتصل بـ [رقم] (يفتح شاشة الاتصال للمراجعة؛ لا يجري المكالمة مباشرة)
- يا مساعد ابحث عن [عبارة]
- يا مساعد اقفل المساعد

## البناء
يتطلب JDK 17 وAndroid SDK 35 وGradle 8.9:
`gradle assembleDebug`

يتولى GitHub Actions بناء نسخة Debug APK عند كل دفع إلى main أو عند تشغيل Workflow يدويًا. سيظهر الملف باسم Sawtak-debug-apk ضمن Artifacts بعد نجاح البناء.

## قيود Android
- يجب فتح التطبيق والضغط على تشغيل الاستماع ومنح إذن الميكروفون. يظهر إشعار دائم أثناء تشغيل الخدمة.
- قد يحتاج التعرف الصوتي إلى الإنترنت حسب مزود خدمة الكلام على الجهاز، وقد يتأثر بتوفير البطارية.
- لا يمكن لتطبيق عادي إغلاق تطبيقات أخرى بالقوة أو تبديل Wi-Fi مباشرة على إصدارات Android الحديثة.
- هذه نسخة تأسيسية، وليست إصدارًا نهائيًا مختبرًا على كل الأجهزة.
